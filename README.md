# Basic Grammar Learning App

A clean, modern, and professional grammar learning web app built with plain HTML, CSS, and JavaScript.

## Features

- 4 quiz categories:
	- Grammar Essentials
	- Collocations
	- Phrasal Verbs
	- Synonyms
- 10 questions per category
- Mixed question types in each category:
	- Single choice
	- Multiple choice
	- True/False
	- Drag and drop
- Progress bar and question navigation (previous/next)
- Scoring with instant feedback
- Big congratulations state with animated confetti for strong scores
- Responsive design for desktop and mobile

## Run Locally

1. Open the project folder.
2. Open `index.html` in your browser.

Optional local server:

```bash
cd /workspaces/basic-grammar-website
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
